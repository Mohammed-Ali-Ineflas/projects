# Data Cleaner Express 🧹

## Overview
Data Cleaner Express is a lightweight, interactive web application designed to automate the data preparation process. Built with Python and Streamlit, it allows users to upload messy CSV files, apply standard data cleaning operations, and download the refined dataset in seconds—no coding required. 

This tool is perfect for handling raw data dumps from clients, e-commerce platforms, or marketing campaigns before passing them into databases or analytics dashboards.

## ✨ Features
- **Quick Upload & Preview:** Upload any CSV file and instantly view its dimensions (rows/columns) and a raw data preview.
- **Deduplication:** Eliminate duplicate rows with a single click.
- **Smart Missing Values (NaN) Handling:** - Option 1: Drop rows containing missing data (Strict cleaning).
  - Option 2: Impute (replace) missing values in numerical columns with the column's mean to preserve dataset size.
- **One-Click Export:** Download the fully cleaned CSV file immediately for downstream analysis.

## 🛠️ Tech Stack
- **Python** (Core logic)
- **Streamlit** (Interactive web interface)
- **Pandas** (Fast data manipulation and processing)
