⚽ FC 25 Ultimate Team Analytics Dashboard
Overview
This project is an interactive data visualization dashboard designed to analyze player statistics from EA Sports FC 25. Built entirely in Python using Streamlit, it allows users to explore player attributes, compare performance metrics, and uncover data-driven insights.

Key Features:

Dynamic Filtering: Filter players interactively by League and Team.

Key Metrics (KPIs): Instantly view the number of players, average age, and the highest-rated player (OVR) for any selected team.

Data Tables: Clean and responsive dataframes displaying essential attributes (PAC, SHO, PAS, DRI, DEF, PHY).

Advanced Visualizations: >   * Top 10 players bar chart based on Overall Rating (OVR).

Scatter plots mapping Pace vs. Shooting and Dribbling vs. Defense, color-coded by player positions using Seaborn.

Tech Stack:

Language: Python

Framework: Streamlit

Data Manipulation: Pandas

Data Visualization: Matplotlib, Seaborn
